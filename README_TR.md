# RepoShelf

RepoShelf, geliştiricinin bilgisayarındaki Git depoları için yerel-öncelikli bir envanter aracıdır. Depoları keşfeder, gerçek Git durumunu ve disk kullanımını gösterir; tarama sırasında depoları değiştirmez.

Kullanım örnekleri ve güvenlik yaklaşımı için [README.md](README.md) belgesine bakın. `fetch` açıkça çağrılmadıkça ağ erişimi yapılmaz.
